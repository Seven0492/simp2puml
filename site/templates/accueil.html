Le diagramme répond au clic

Un clic sur une propriété ramène à sa ligne. Un Ctrl+clic place le curseur au caractère près, ou sélectionne le jeton d'une flèche.

Les flèches se cliquent sur toute leur longueur. Là où elles se croisent, un petit menu demande laquelle.

Cliquer dans le diagramme

Il aide à écrire

L'autocomplétion connaît les mots-clés selon le contexte et les noms déclarés dans le document. Une erreur est signalée à sa ligne.

Écrire

Net à tous les zooms

L'aperçu est dessiné en vectoriel, sans image bitmap. Dans le texte, Ctrl++ agrandit le texte plutôt que le diagramme.

SIMP inclus

Un projet SIMP s'ouvre dans un nouvel onglet, sans rien écrire à côté de la source. Le convertisseur s'utilise aussi seul, en ligne de commande.

Ligne de commande

Télécharger

La dernière version, prête à lancer : extraire l'archive, puis ouvrir le lanceur de son système. Au premier lancement, il installe au besoin un Python privé, sans droits administrateur.

Windows Linux

Windows et Linux, x64. Notes de version et sommes SHA-256 · Premier lancement

Ou construire l'éditeur depuis les sources, avec Nim et Rust :

git clone https://git.sethmartin.dev/Seth_Martin/simp2puml.git
cd simp2puml/renderer && nimble build
cd ../editor && cargo build --release
./target/release/puml-editor diagramme.puml
